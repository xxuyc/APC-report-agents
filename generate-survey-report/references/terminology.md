# 术语表（V0.2）

| 推荐表述 | 避免混用 | 说明 |
|---|---|---|
| 污水处理厂 | 污水厂、水厂交替使用 | 首次使用全称，后文可简称“厂区” |
| 一、二期 | 12期、1、2期 | 阶段名称使用正式中文顿号 |
| 三期 | 3期 | 阶段名称使用正式中文 |
| 精确曝气控制 | 智能曝气、自动曝气随意切换 | 仅在模块适用时使用 |
| 智能碳源投加 | 精准加药、碳源自控混用 | 对应碳源投加模块 |
| 智能化学除磷 | 除磷加药自控混用 | 对应化学除磷模块 |
| 在线仪表 | 在线表、分析表 | 指可连续采集过程数据的仪表 |
| PLC 控制系统 | PLC 柜、控制柜混用 | 设备实体需按现场事实描述 |
| 上位监控系统 | 中控、SCADA 随意替换 | 已确认软件类型时可写 SCADA |
| 建设需求 | 现有配置 | 拟新增设备和改造目标不得写成现状 |
| 待确认 | 未知、没有 | 资料不足不等于现场不存在 |

数字与单位之间留一个半角空格；设备数量、型号和量程必须来自明确来源。
