# 现状评估章节映射（V0.1）

| 报告章节 | Excel 输入 | 写作目标 |
|---|---|---|
| 3.1 调研范围及资料依据 | 填写说明、资料清单 | 独立报告可使用；嵌入总体方案且金标准从 3.2 开始时省略。 |
| 3.2 项目概况及工艺现状 | 01项目基本信息、02全厂工艺 | 描述规模、分期、工艺、水量、水质与现有运行边界。 |
| 3.3 自控与数据基础 | 03自控与数据 | 描述 PLC、SCADA、网络、历史数据、远控和数据完整性。 |
| 3.4 精确曝气系统现状 | 04精确曝气调研 | 描述池型、风机、阀门、仪表、控制方式与运行问题。 |
| 3.5 智能碳源投加系统现状 | 05智能碳源投加调研 | 描述药剂、投加点、泵阀、仪表、控制方式与限制。 |
| 3.6 智能化学除磷系统现状 | 06智能化学除磷调研 | 描述药剂、加药点、泵阀、仪表、控制方式与限制。 |
| 3.7 回流与排泥系统现状 | 07、08 | 项目范围已确认但资料不足时，保留章节并列待确认事项。 |
| 3.8 主要问题、建设约束及待确认事项 | 全表、校验结果 | 汇总可证实问题、项目边界和未确认信息；不写详细技术方案。 |

不适用模块不应被解释为“未建设”或“能力不足”。Excel 汇总状态与人工批准章节冲突时，以项目级金标准配置为准并记录冲突。
