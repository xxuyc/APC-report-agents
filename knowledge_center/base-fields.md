# 飞书 Base 七表字段合同

| 表 | 必需字段 |
|---|---|
| 项目台账 | 项目ID、项目名称、项目别名、项目类型、报告类型、处理工艺、设计规模、规模档位、排放标准、地域、气候、设备与成本边界、允许复用范围、复用状态、披露方式、状态 |
| 资料与证据 | 资料ID、项目ID、文件名、文件链接、SHA-256、来源用途、版本、复用状态、允许用途、披露方式、证据定位、状态 |
| 知识条目 | 知识ID、项目ID、类型、标题、内容、关键词、允许用途、复用状态、披露方式、来源ID、状态、版本 |
| 项目指标事实 | 项目ID、指标ID、指标名称、值、单位、统计周期、时间粒度、公式版本、指标定义、数据边界、证据来源、QA状态、复用状态、允许用途、披露方式、运行ID、状态 |
| 需求与反馈 | 记录ID、项目ID、类型、内容、状态，以及系统方向、关键输入、表达偏好、通用规则候选、流程缺陷等业务字段 |
| Agent运行 | 运行ID、项目ID、Agent类型、状态、目标/参考项目、检索意图、知识快照SHA-256、代码版本、QA、产物链接、内容哈希 |
| 知识变更 | 变更ID、项目ID、变更前、变更后、来源、审批方式、影响范围、回归结果、替代关系 |

枚举值以 `base-schema.json` 为准。正式报告自动实名引用只接受 `reuse_status=named_reference` 且 `disclosure_mode=named`。
